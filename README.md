# Spears & Tears — قناة التاريخ والحروب القديمة

مستودع إدارة القناة: الاستراتيجية، خطة المحتوى، القوالب، والسكربتات.

## الهيكل
- `strategy/channel-strategy.md` — هوية القناة، الجمهور، محاور المحتوى، ومؤشرات الأداء.
- `strategy/content-calendar.md` — أول 12 فيديو مقترح مع جدول النشر.
- `templates/video-script-template.md` — قالب كتابة سكربت أي فيديو.
- `templates/seo-checklist.md` — قائمة تحقق للعنوان والوصف والوسوم والصورة المصغّرة.
- `scripts/` — السكربتات الجاهزة للحلقات.
- `assets/brand/` — شعار القناة (logo.png 800×800)، الغلاف (banner.png 2560×1440)، وشخصية الراوي Sobius.
