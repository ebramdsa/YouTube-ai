# قائمة تحقق قبل النشر

## العنوان
- [ ] أقل من 60 حرفًا ويحتوي الكلمة المفتاحية (اسم المعركة/الحضارة).
- [ ] يثير فضولًا دون تضليل.

## الصورة المصغّرة
- [ ] عنصر بصري واحد واضح (قائد، جيش، خريطة).
- [ ] نص لا يتجاوز 3–4 كلمات بخط عريض.
- [ ] تباين ألوان قوي وواضحة على شاشة الهاتف.

## الوصف
- [ ] أول سطرين يلخّصان الفيديو بالكلمات المفتاحية.
- [ ] فصول زمنية (Chapters).
- [ ] قائمة المصادر.
- [ ] روابط الفيديوهات والسلاسل المرتبطة.

## الوسوم والإعدادات
- [ ] 8–15 وسمًا (عربي + إنجليزي): اسم الحدث، الحقبة، "تاريخ"، "وثائقي".
- [ ] إضافة الفيديو لقائمة التشغيل المناسبة.
- [ ] شاشة النهاية وبطاقات لفيديوهات ذات صلة.
- [ ] ترجمة عربية مصحّحة + ترجمة إنجليزية.
